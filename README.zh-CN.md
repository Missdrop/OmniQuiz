导入笔记、课件或教材，连接你自己的 AI，点击开始练习。题目快刷完时，软件会自动补充下一批，直到你结束练习。

资料与学习进度保存在本机，不需要注册万物一点通账号。

## 可以做什么

- **持续刷题**：只需开始一次，题量不足时自动补题；结束练习或离开练习页即可停止。
- **按科目建库**：每个资料库拥有独立的题目、错题和学习进度。
- **导入资料**：支持 TXT、Markdown 和可选中文字的 PDF。电脑端可关联文件夹，手机端可导入文件或 ZIP。
- **看懂答案**：每道题都有解析和资料原文摘录，方便核对。
- **复习错题**：按间隔重复安排复习，提前练习不会跳过掌握过程。
- **备份与迁移**：导出所有资料库，恢复时创建独立副本，不覆盖现有资料。
- **离线练习**：已生成的题目可以离线作答。
- **按习惯设置**：支持中英文界面、白天与黑夜模式，以及独立的出题语言设置。

## 开始使用

1. **连接 AI**：打开「设置 → 配置 AI → 添加连接」，选择「ChatGPT 订阅」或「OpenAI 兼容 API」。测试连接是可选操作；首次配置成功自动启用，其他连接独立保存。
2. **创建资料库**：在「资料库」页点击「创建资料库」。电脑端可以关联已有文件夹，也可以使用软件管理的文件夹。随后导入资料，或体验内置示例。
3. **开始练习**：进入「练习」，选择范围并点击「开始练习」。待答题不足时会自动补充。点击「结束练习」或离开此页即可停止生成；错题可在「错题复习」中重练。

首次启动时没有预设资料库。外观、界面语言和出题语言默认跟随系统，手动选择后自动保存。出题语言位于「设置」顶部、界面语言下方，对 API 和 ChatGPT 订阅两种接入方式统一生效；已有题目不改变语言。

外观也可以通过侧栏或手机顶部的快捷按钮切换。练习只会提前缓存有限数量的题目；如果服务请求失败，仍可继续作答缓存题目，再点击「重试补题」。

生成新题需要联网，会消耗所选服务的订阅额度或 API 用量。

### 样题、样卷与出题要求

在「练习 → 样题与出题要求」中，粘贴样题，或导入 TXT、Markdown、可选中文字的 PDF 样卷，并填写额外要求，例如「多出情境应用题，解释错误选项的原因」。设置仅属于当前资料库，并包含在资料库备份中；扫描版 PDF 需要先识别文字。

样题用于参考风格和难度，答案和引用仍以学习资料为准。目前生成四选一单选题。保存后保留所有现有题目、当前已选答案、答题记录和错题，新要求仅用于后续生成。仅导入草稿不会发送给 AI，实际出题时会把要求和限定长度的样题摘录发送给所选服务。

资料库可以整体迁移：`.omniquiz/quiz.sqlite` 保存题目、答题记录、错题复习及题目评价；`.omniquiz/guidance/requirements.md` 保存可编辑的出题要求，`pasted-example.md` 保存粘贴的样题，`examples/` 保存导入样卷的原文件副本。也可以直接修改这些文件或放入支持的样卷，后续补题会重新读取。学习资料扫描会跳过 `.omniquiz`。旧的集中式数据库自动迁移，保留原文件供恢复。请先关闭软件，再复制或移动整个资料库并重新关联文件夹；全局界面设置和安全存储中的账号凭据仍属于本机。

点击选项即可提交答案，无需再次确认。通过「好」「不好」「出错了？」评价题目；最近的评价和备注会随后续出题请求发送给 AI，帮助改进题目，不会因为点击评价而额外发起一次付费请求。评价不能代替资料原文作为证据。标记出错会隐藏该题但保留答题历史。「查看原始资料」可打开引用对应的 PDF 原页并缩放、滚动；原文件丢失或被修改时，会明确提示并显示保存的文字摘录。

补题会显示读取资料、请求模型、校验和保存等阶段及耗时。每批最多 5 题，模型请求最多等待 3 分钟；超时后停止，不自动重复付费请求，已有题目仍可作答。本地状态日志位于 `.omniquiz/generation.log`，不记录提示词、资料、密钥或账号详情。

### 选择当前使用的 AI

在「配置 AI」中可命名、保存多个连接。OpenAI 官方 API 和 CLIProxyAPI 都选择「OpenAI 兼容 API」，填写各自的地址即可。「保存连接」独立保存新增配置，不切换当前连接；点击「使用」或「保存并使用」才明确切换。编辑、测试备用连接不会影响正在使用的连接。切换保留缓存题目，只影响后续生成。删除当前连接或退出其账号会停止补题，不会自动改用其他服务。练习页始终显示后续出题所用的连接与模型。

### 直接使用 ChatGPT 订阅

在「设置 → 配置 AI → 添加连接 → ChatGPT 订阅」点击「继续使用 ChatGPT」，在本机浏览器中完成授权，再返回软件。登录后自动保存账号和可用模型。修改模型后点击「保存连接」，或用「保存并使用」启用它；「测试连接」是可选操作。顶部的出题语言仍独立自动保存。

如果模型列表加载失败，账号仍会保留；点击「获取可用模型」完成设置。这种方式不需要 API 密钥、网关或始终开机的电脑，使用你授权的订阅额度，可用性取决于账号权限。

Android 和 iOS 使用原生浏览器组件及本地回调。自动化测试不能代替真机登录验证。如果授权过程中应用被系统终止，请重新开始登录。账号凭据保存在操作系统的安全存储中，不包含在资料库备份里。

### 可选：通过 CLIProxyAPI 网关接入

你也可以连接自己的 [CLIProxyAPI](https://github.com/router-for-me/CLIProxyAPI) 网关，使用已在网关中登录的服务商账号，包括 ChatGPT/Codex 路由。

添加「OpenAI 兼容 API」连接，填写网关以 `/v1` 结尾的 API 地址和**客户端 API 密钥**，获取可用模型后保存，测试连接是可选操作。可用模型和用量限制取决于网关与所连接的账号。

同一台电脑上的常见地址为 `http://127.0.0.1:8317/v1`。手机需要填写它能访问的 **HTTPS** 网关地址；手机上的 `localhost` 指手机自身。使用此方式时需保持网关运行；希望手机独立使用，请选择上方的直接登录。详见[网关与移动端说明](docs/development.md#subscription-gateways)。

### 软件更新

Microsoft Store 版本由商店分发和更新。以下下载与安装控制适用于独立发行版本。

软件默认在启动时检查新的**稳定版本**，可在「设置 → 应用更新」关闭自动检查，或手动检查。发现更新后会显示版本说明，并提供「稍后提醒」「跳过此版本」和「立即更新」。跳过后不再启动提醒该版本，手动检查仍可查看。**更新始终自愿。**

只有点击「立即更新」才会下载。软件会校验文件大小与 SHA-256，再打开 Android/Windows 系统安装器，或替换可写的 macOS/Linux 应用并重启。安装时可能需要系统权限。下载可取消，下载时关闭提示会推迟安装；资料库和凭据保留在应用数据目录中。

检查、下载或安装失败时，可通过「官方下载页面」手动下载。系统管理或只读位置中的桌面应用可能需要手动安装。iOS 当前仅提供更新提醒和官方下载页，无法直接安装未签名的发布归档。

### 文件与备份

资料文件夹会在启动、切换资料库，以及没有练习进行时返回应用后扫描。软件保持打开时修改了文件，可点击「扫描文件夹」；扫描会导入新增和修改过的文件。

源文件丢失时会显示标记，但已导入的文本、题目和进度仍然保留。在软件中移除资料，只会将它排除出后续扫描，不删除原文件；可从「已排除文件」重新导入。隐藏文件和符号链接会跳过。

手机端使用应用管理的文件夹，支持导入文件或 ZIP。ZIP 保留子目录结构，跳过隐藏和不支持的文件。请使用未加密 ZIP：压缩包及解压总大小均不超过 100 MB、最多 1,000 项、单份资料不超过 20 MB。AI 连接、外观、界面语言与出题语言在各资料库之间共享。

更换设备或重装前，可在「设置 → 备份资料库」导出备份。恢复时添加副本，不覆盖现有资料。丢失的原文件无法打包，但其已导入文本和学习进度仍会保留，导出后会提示缺失原文件的数量。备份不包含 AI 配置和密钥，请妥善保管。

## 数据与隐私

完整[隐私政策](assets/legal/privacy_zh.txt)也可在软件设置中离线查看。对于错误或不当的 AI 内容，可从软件内的反馈入口向开发者报告；GitHub 报告公开可见，应用不会自动附加题目内容或凭据。

资料、题目和进度存储在本机。生成题目时，选中的资料片段会直接发送到你配置的 AI 服务。API 密钥保存在操作系统安全存储中。万物一点通没有自建后端，也不收集使用分析数据。

AI 可能出错，请结合原文核对答案，并隐藏有问题的题目。扫描版 PDF 需先进行 OCR，转换为可选中文字的文件再导入。

## 开发

使用 Flutter 构建。完整的环境配置、测试和平台说明见[开发文档（英文）](docs/development.md)。

macOS / Linux：

```sh
./scripts/bootstrap
./scripts/flutter run -d macos
```

Windows PowerShell：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/bootstrap.ps1
powershell -ExecutionPolicy Bypass -File scripts/flutter.ps1 run -d windows
```

需要安装对应平台的原生构建工具。脚本会将 Flutter 与缓存保存在 `.tooling/`。欢迎通过 Issue 反馈问题，或向 `dev` 分支提交聚焦的 Pull Request。
