万物一点通（OmniQuiz）隐私政策
更新日期：2026 年 10 月 28 日

开发者：Missdrop
联系与反馈：https://github.com/Missdrop/OmniQuiz/issues

1. 本地数据
学习资料、解析后的文本、生成的题目、答题记录、错题和设置保存在用户设备上。我们不运营接收这些数据的自建服务器，应用不内置广告、使用行为分析或向开发者自动发送的崩溃报告。

样卷原文件副本保存在资料库的 .omniquiz/guidance/examples 中；粘贴的样题及出题要求保存为可编辑的本地文件。这些文件、解析文本和题目、答题、错题复习数据库均包含在导出的资料库备份中。题目评价与可选的错误备注也保存在该数据库。有限大小的本地补题日志记录时间、处理阶段和受控的错误信息，不记录提示词、资料内容、凭据或账号详情；日志不包含在备份中。出题时，会将要求和限定长度的样题摘录连同学习资料片段发送给所选 AI 服务。

2. AI 服务与资料发送
只有用户主动开始练习、测试连接或执行其他相关操作时，应用才请求所选 AI 服务。生成题目会将所选资料片段、出题要求和用于减少重复的近期题目发送给用户配置的服务或网关。连接测试也会发送测试请求。服务会接收到认证所需的信息及网络连接信息，例如 IP 地址。
这些第三方按照各自的政策处理接收的数据，保存时间、处理位置及用途取决于所选服务。使用网关时，网关及其上游服务也会处理请求。请勿在未经许可的情况下发送他人的个人信息或敏感资料。

最近的题目评价、被评价题目的摘要及可选错误备注会随后续出题请求发送给所选 AI，以帮助改进题目质量。点击评价不会额外发起一次推理请求，也不会自动向开发者提交报告。评价仍须服从资料原文约束。

3. 账号与凭据
使用 ChatGPT 登录时，应用会处理账号邮箱、账号标识、应用注册信息和授权令牌，用于显示账号、获取模型和使用已授权的服务。登录和刷新授权会连接 OpenAI。API 密钥和登录凭据保存在操作系统的安全存储中，不包含在应用导出的资料库备份中。不同 AI 接入方式可能需要有效的服务账号或付费额度；应用不处理银行卡或支付信息。

4. 更新
独立发行版本会按设置连接 GitHub 检查版本；只有点击更新后才下载安装文件。可关闭启动检查，并可跳过更新或取消下载。商店构建由 Microsoft Store 分发和更新，不使用应用自身的 GitHub 下载安装功能。GitHub、Microsoft Store 和操作系统分别按照其政策处理网络请求、下载和商店诊断信息。

5. 报告不当或错误的 AI 内容
应用提供 GitHub 问题反馈入口。点击入口会打开公开问题的新建页面，应用不自动附加题目、资料、账号或凭据。用户自行填写并确认提交后，报告将对外公开并由 GitHub 托管；其保存与删除受 GitHub 规则约束。请勿在报告中公开私人资料、账号信息或密钥。开发者会查看报告，并根据实际问题采取修复、改进或其他适当措施。

6. 用户控制与删除
用户可停止生成、修改服务设置、退出 ChatGPT 登录，并在 ChatGPT 设置中撤销应用连接。在应用内移除资料会将其排除出扫描，不删除原始文件，也不应被视为删除所有关联的历史数据。请先退出账号以清除应用保存的登录凭据。关闭应用后，删除资料库的 .omniquiz 目录可清除该库的题目、记录、样题和要求，目录外的学习资料仍保留。本机全局设置及迁移前保留的旧数据库副本位于应用数据目录，需另外管理。原始文件、自行导出的备份及第三方已接收的数据也需分别管理。备份可能包含私人学习资料，请妥善保管。

7. 适用范围与变更
本政策适用于万物一点通本身；用户所选 AI 服务、网关、GitHub、Microsoft Store 和操作系统有各自的政策。我们会随软件功能和数据处理方式变化更新本政策，并在应用内提供最新随版本发布的文本。如对数据处理有疑问，请通过上述项目反馈渠道联系，勿在公开报告中提供敏感信息。
